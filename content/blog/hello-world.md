This blog is live. Posts are plain Markdown files in a git repo, built with Hugo and hosted free on GitHub Pages.

## Writing a new post

Create a file in `content/blog/`, for example `content/blog/my-next-post.md`:

```markdown
---
title: "My next post"
date: 2026-10-20
description: "One line summary."
---

Write here.
```

Then commit and push. It goes live in about a minute.
